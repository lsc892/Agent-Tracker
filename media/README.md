# media

Webview 안에서 실행되는 화면 코드와 공통 스타일을 둔다.

- [dashboard.js](dashboard.js): 통계 필터·표·차트를 표시하고 사용자 요청을 확장에 전달한다.
- [diagnostics.js](diagnostics.js): 파일별 수집 상태·오류와 페이지 조회를 처리한다.
- [color-settings.js](color-settings.js): 색상 입력·미리 보기와 설정 저장 요청을 처리한다.
- [localization.js](localization.js): Webview 번역을 초기화하고 열린 화면의 언어를 갱신한다.
- [dashboard.css](dashboard.css): 통계·진단·색상 설정 화면의 공통 배치와 테마 스타일을 정의한다.
