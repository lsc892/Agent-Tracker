# icon

확장과 제공자의 시각적 식별에 쓰는 로고·아이콘 폰트를 둔다.

- [AgentTracker_Icon.png](AgentTracker_Icon.png): VS Code에 표시할 확장 아이콘을 제공한다.
- [claude.svg](claude.svg): Claude 로고를 제공한다.
- [codex.svg](codex.svg): Codex 로고를 제공한다.
- [agent-tracker.woff](agent-tracker.woff): 제공자 로고와 quota 백분율을 표시하는 아이콘 글리프를 제공한다. `U+E010`~`U+E01A`는 왼쪽 끝에 붙는 0~100% 채움이다.
