# localization

지원 언어 목록과 호스트·Webview·VS Code 설정 화면의 번역 데이터를 둔다.

- [languages.json](languages.json): 지원 언어·표시 이름·VS Code 언어 매핑을 정의한다.
- [locales/](locales/README.md): 호스트와 Webview가 공유하는 언어별 원본 번역을 둔다.
- [package.nls.json](package.nls.json): VS Code 확장 manifest의 기본 번역을 제공한다.
- [package.nls.en.json](package.nls.en.json): 영어 manifest 번역을 제공한다.
- [package.nls.es.json](package.nls.es.json): 스페인어 manifest 번역을 제공한다.
- [package.nls.fr.json](package.nls.fr.json): 프랑스어 manifest 번역을 제공한다.
- [package.nls.ja.json](package.nls.ja.json): 일본어 manifest 번역을 제공한다.
- [package.nls.ko.json](package.nls.ko.json): 한국어 manifest 번역을 제공한다.
- [package.nls.zh.json](package.nls.zh.json): 중국어 manifest 번역을 제공한다.
- [package.nls.zh-cn.json](package.nls.zh-cn.json): 중국어 간체 manifest 번역을 제공한다.
