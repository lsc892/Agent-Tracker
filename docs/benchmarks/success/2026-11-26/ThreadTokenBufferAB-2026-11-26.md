# 응답 토큰 ArrayBuffer A/B

사용자는 파싱·집계의 V8 힙을 줄이면서 RSS 증가를 피하려 했다. A는 `8f2b0b4`의 응답·구형 누계 토큰 객체다. B는 같은 경로에서 토큰 숫자를 `Float64Array`로 보관하고 파일 Worker에서 원래 `ArrayBuffer`를 이전하는 구현이다.

## 메모리 변화

실로그의 집계 직전 힙은 31.58 → 26.39 MiB, 집계 직후는 36.70 → 25.15 MiB였다. 갱신 완료 후 강제 GC를 한 번 실행하면 7.21 → 7.22 MiB였다. 효과는 갱신 도중 나타났으며, 피크 차이에는 수치 저장 방식과 임시 할당·GC 시점 변화가 함께 들어 있다. 최종 스레드 집계 시간은 9.18 → 11.43 ms였고 전체 갱신 시간은 실행별 범위가 겹쳤다.

실로그 병렬 파싱에서 수집 스레드의 집계 직전 `external`은 2.14 → 5.44 MiB, `arrayBuffers`는 양쪽 모두 0.018 MiB였다. Node 24.14.1의 `external`은 V8 통계에서, `arrayBuffers`는 현재 스레드의 Node 할당기에서 읽는다. Worker는 이미 할당된 바이트 저장소를 이전하므로 수신 스레드가 할당한 바이트만 나타내는 값으로는 이전분을 셀 수 없다. 순차 실행한 합성 10,000건에서는 집계 직전 두 지표가 각각 약 0.40 MiB 늘었다. [Node.js 메모리 지표](https://nodejs.org/download/release/latest-v24.x/docs/api/process.html#processmemoryusage) · [지표 구현](https://github.com/nodejs/node/blob/v24.14.1/src/node_process_methods.cc#L204-L229) · [전송 구현](https://github.com/nodejs/node/blob/v24.14.1/src/node_messaging.cc#L197-L202)

같은 빌드와 로그를 사용한 후속 측정에서 실로그 최초 수집의 수집 스레드 GC 멈춤 합계 중앙값은 17.35 → 14.05 ms였다. 파일 Worker를 포함한 GC 횟수는 478 → 513회였다. [자연 GC 측정](ThreadTokenGcAB-2026-11-26.md)

## 측정 및 검증

- Windows x64, AMD Ryzen 5 7500F, Node 24.14.1, SQLite 3.51.2, Asia/Seoul 환경에서 측정했다. 조건마다 준비 3쌍 뒤 AB·BA를 10쌍씩 교대했다. 측정마다 새 Node 프로세스와 SQLite DB 사본을 썼고 OS 파일 캐시는 유지했다. 힙과 외부 메모리는 제품 갱신을 실행하는 스레드에서 5ms 간격과 진행·스레드 집계 경계에 읽었다. RSS는 파일 Worker와 SQLite를 포함하는 해당 프로세스 전체다. VS Code 확장 호스트와 Webview 메모리는 미측정이다.
- 실로그 733파일은 일반·압축 466,960,401바이트다. 원본 검산은 중복을 접은 명시 응답 19,626건과 구형 누계 사용량을 계산했다. SQLite에는 최종 714스레드와 3,704,622,224토큰을 저장했다. 합성 데이터는 제공자별 절반, 스레드당 50건·5건, 저장 프로젝트 그룹 2개다. 전체 기간과 미상 일자를 포함하며 완료 스레드가 평균의 분모다.
- 추가 시나리오는 같은 사전 SQLite DB를 복원한 뒤 기존 Codex 파일에 입력 123·출력 7토큰을 추가했다. 실로그는 기존 11.21 MiB 압축 파일을, 합성은 각각 32.44 KiB·3.25 KiB 일반 파일을 다시 읽었다. 세 입력 모두 파일 1개를 파싱하고 저장 COMMIT 1회가 있었다.
- 측정 120쌍에서 전후 파일 처리 건수, 입력·출력·합계와 여덟 SQLite 테이블의 논리 데이터 해시가 일치했다. 원본 JSONL 독립 검산과 제공자별 입력·출력을 대조했으며 1건 추가는 세 규모 모두 정확히 130토큰 증가했다. 네 조회의 그룹·건수·평균은 일별 행을 다시 합산해 확인했다. SQLite 무결성·외래 키 확인과 사본 해시 재검증을 통과했다. [원시 표본](ThreadTokenBufferAB-2026-11-26.json)
