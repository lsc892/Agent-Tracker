# 스레드 토큰 집계 정합성 A/B

응답 단위로 사용량을 비교하면 Claude의 반복 응답과 Codex fork의 복사분을 제외하면서 중단 전 사용량까지 보존할 것으로 예상했다. A는 작업 시작 당시의 파서 v24 작업 트리를 고정한 빌드다. `21ff22b` 이후 미커밋 변경도 포함한다. B는 응답별 사용량과 확인된 누계 증가분을 스레드별 한 행으로 합산하는 파서 v25다. [파싱 및 합산 규칙](../../../refrences/LogParsingFields.md)

## 실제 로그 결과

Claude 12파일과 Codex 691파일의 고정 사본으로 각 빌드를 빈 SQLite DB에 한 번씩 최초 수집했다. 전체는 429,580,467바이트이며 668파일이 압축 로그다. Windows x64, Node 24.14.1, SQLite 3.51.2, 파일 Worker 4개, 시간대 `Asia/Seoul`을 사용했다. 운영체제 파일 캐시는 비우지 않았고 예열은 없었다. 구형 누계가 사이에 다른 행을 두고 반복되는 경우를 보완한 뒤 최종 B를 한 번 측정했다. 비교에는 먼저 얻은 A 표본을 재사용했다. [원시 표본·입력 및 빌드 해시](ResponseThreadAccountingAB-2026-11-24.json)

| 제공자 | 변경 전 토큰 | 변경 후 토큰 | 원본 독립 검산 | 감소한 과다 집계 |
| --- | ---: | ---: | ---: | ---: |
| Claude | 59,770,061 | 10,241,517 | 10,241,517 | 49,528,544 |
| Codex | 3,694,045,129 | 3,461,396,291 | 3,461,396,291 | 232,648,838 |
| 합계 | 3,753,815,190 | 3,471,637,808 | 3,471,637,808 | 282,177,382 (7.52%) |

독립 검산은 제품 집계기를 호출하지 않고 JSONL을 별도로 해석했다. Claude 사용량 422행에서 응답 100개, Codex 새 형식에서 응답 18,101개를 확인했다. 부모와 일치한 Codex 복사 행 4,557개를 제외했다. 혼합 형식에서 첫 응답 이전의 10,626,023토큰과 누계가 뒷받침한 누락분 384,742토큰을 반영했다. 변경 후에는 제공자별 입력·출력이 각각 일치했고, 스레드 총합과 모델·일·월·세션·프로젝트별 조회 합계가 일치했다. 스레드 행은 685개에서 684개로 바뀌었으며 두 DB 모두 SQLite 무결성과 외래 키 검사를 통과했다. 구형 누계가 재등장하는 경우와 중단 전에 기록된 응답의 최고 사용량이 보존되는 경우도 별도 확인했다. [원본 검산 코드](../../../../tests/benchmarks/thread-usage-oracle.cjs)

## 시간과 메모리 관측

| 지표 | 변경 전 | 변경 후 | 변화 |
| --- | ---: | ---: | ---: |
| 최초 수집·저장 | 4,193.18 ms | 3,672.80 ms | −12.41% |
| 변경 원본 준비 | 3,917.24 ms | 3,380.27 ms | −13.71% |
| 스레드 집계 | 3.21 ms | 50.32 ms | +47.11 ms |
| 프로세스 피크 RSS | 377.40 MiB | 478.73 MiB | +26.85% |
| 메인 스레드 피크 V8 사용 힙 | 15.98 MiB | 42.93 MiB | +168.72% |
| 수집 종료·강제 GC 후 메인 V8 사용 힙 | 7.32 MiB | 7.60 MiB | +0.28 MiB |

RSS는 파일 Worker와 네이티브 영역을 포함하는 프로세스 값이고 V8은 메인 스레드 값이다. 5ms 간격과 수집 진행 시점에 표본을 땄다. 집계 전 보조 메모리는 A의 파일별 축약값에서 B의 응답·누계 기록까지 늘었다. 본문 순회 시간의 차수는 원본 바이트에 선형으로 유지된다. 한 쌍의 측정으로 안정적인 성능 향상이나 RSS 증가의 전체 원인을 판정하기는 어렵다. 채택 근거는 원본과의 정합성이다.

일·월·세션·프로젝트별 조회 지연의 표본은 원시 JSON에 기록했다. 사용자가 요청한 고정 실로그 최초 수집 범위에 맞춰 1건 추가, 무변경 갱신, 이전 DB 이관, 합성 1만·100건은 미측정이다. 부모의 원본이 없는 경우 복사 여부를 확인할 수 있는 범위는 제한된다.

## 재실행

아래 실행기는 [고정 입력 생성 함수](../../../../tests/benchmarks/incremental-refresh.cjs)의 `makeSnapshot()`이 반환하는 자료를 JSON으로 저장한 사본과 `dist/src`가 준비된 두 빌드를 사용한다. 경로가 포함된 원본 사본 및 SQLite DB는 로컬 캐시에 둔다.

```powershell
node --no-warnings tests/benchmarks/thread-usage-ab.cjs '<A 빌드 루트>' '<B 빌드 루트>' '<고정 입력 manifest>' '<새 JSON 출력>'
```
