원시 JSON·압축 로그의 측정값과 당시 경로·소스 해시는 변경하지 않는다. 문서 링크는 현재 보관 경로를 사용한다. 보존된 실행기의 기본 출력 경로와 재실행 옵션은 해당 날짜의 README를 따른다. 로컬 재실행·smoke 산출물은 기존 `tests/results/benchmarks/`에 둔다.
2026-11-08에 정리한 실험 워크트리의 중복 기록은 합쳐 보존했다. [보관 명세](2026-11-08/WorktreeArchive-2026-11-08.json)에 파일별 원본·보관본 SHA-256과 중복 보고서 선택 근거를 기록하며, 당시 명령의 로컬 캐시·실행기가 현재 남아 있음을 뜻하지 않는다.
