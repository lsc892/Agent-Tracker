## 3. 확인한 손익

- 실제 전체 재수집의 피크 힙은 20쌍 모두 줄었고 중앙값은 22.86MiB 낮았다. 최종 집계 시간은 20쌍 모두 늘었다. 전체 시간의 중앙값 차이는 73.55ms였으며 실제 표본의 두 사분위 범위는 겹쳤다. 실제 1건 추가는 중앙값이 2.27ms 짧아졌지만 B가 빠른 표본은 8/20쌍이었다. 네 평균 조회의 중앙값 차이는 세 입력에서 모두 0.34ms 이내였다.
- 합성 10,000요청 재수집은 B가 20/20쌍에서 느렸다. 변경 파일 준비는 408.91→504.16ms, 최종 집계는 125.03→190.59ms였다. 1건 추가는 10,000요청에서 16/20쌍, 100요청에서 18/20쌍 느렸다. 합성 100요청의 1건 추가 증가폭은 절대값으로 2.22ms였다.
- 시간 표본과 분리한 빈 DB 계측에서 실제 원본의 B는 winner 18,497행을 임시 테이블에 쓰고 유효한 16,156행을 읽었다. 최종 맵 비교는 16,156→10,201회로 줄었다. B의 임시 쓰기와 행 조회·DTO 복원에 각각 190.14ms와 127.02ms가 관측됐다. 합성 10,000요청에서는 최종 맵 비교가 10,000→0회로 줄어도 후보 10,000행을 쓰고 다시 읽었으며, 계측에서 각각 53.85ms와 60.37ms가 들었다. 쓰기는 파일 준비 구간에, 조회·복원은 최종 집계 구간에 포함된다. 이 계측은 빌드·입력당 1회이며 위 시간 중앙값과 별개다. [파일 준비](../../../src/summary/scanner/sourcePool.ts) · [최종 비교](../../../src/summary/aggregation/memoryAggregate.ts)
- 실제 대화 로그에서 확인된 이득은 전체 재수집 힙 절감이다. 재수집 최종 집계와 합성 입력의 갱신에서는 비용이 늘었다. 관측된 시간·메모리 차이에는 선택적 winner 맵과 임시 테이블 전환이 모두 반영된다.

## 4. 측정 조건과 정합성

- Windows x64, Intel Core i5-8250U, Node 24.19.0, SQLite 3.53.3에서 빌드별 독립 프로세스와 최대 4개 파일 Worker를 사용했다. 입력과 작업마다 준비 3쌍 뒤 A→B와 B→A 순으로 각각 10쌍씩 실행했다. OS 파일 캐시는 유지했다. 갱신 시간은 `refreshSummary` 호출부터 COMMIT과 갱신 종료까지다. 입력 준비·추가 텍스트 쓰기·원복·빈 DB 스키마 생성·강제 GC·정합성 검사는 타이머 밖에서 수행했다. 1건 추가 표본 뒤에는 추가한 줄을 지우고 복원 갱신을 실행해 최초 요청 수와 토큰 합계를 확인했다.
- 실제 사본은 일반 JSONL 418개, 616,959,493바이트, 922요청과 1,849,943,425토큰이다. 1건 추가에는 16,159,523바이트의 일반 Codex 메인 로그 사본을 사용했다. 실제 추가 갱신의 본문 읽기량은 두 빌드 모두 27,140,525바이트였다. 합성은 요청별 고정 산식으로 Claude·Codex를 절반씩 배분하고 10개 프로젝트와 최대 14일에 배치했다. 10,000요청은 100세션·세션당 100건, 100요청은 10세션·세션당 10건이다. 최초 토큰 합계는 각각 6,340,000개와 18,400개다.
- 1건 추가 저장 직후 `queryUsagePage`로 일·월·세션·프로젝트별 결과의 전체 페이지를 가져오는 시간을 쟀다. 기간은 2020-01-01 UTC 이상, 2035-01-01 UTC 미만이며 시각 미상도 포함했다. 일·월 경계는 Asia/Seoul 기준이다. 평균의 분모에는 빈 완료 요청을 포함한 모든 완료 요청을 사용했다.
- 준비를 포함한 207쌍에서 요청 수·토큰 합계·본문 읽기량과 요청·모델·도구·비용 행 해시가 일치했다. 두 합성 입력의 최초 요청 수와 토큰 합계는 생성기의 기대값과 같았다. 모든 입력에 정확히 1요청·130토큰이 추가됐다. 무변경과 추가 갱신 뒤의 조회 1,104건은 정규화 요청으로 독립 계산한 그룹 수·토큰 합계·평균과 맞았다. 반복 종료 후 사본의 원본 해시도 확인했다. [원시 표본과 입력·빌드 해시](SQLiteWinnerRefreshAB-2026-11-23.json)
