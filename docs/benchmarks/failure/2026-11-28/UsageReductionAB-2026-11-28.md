## 판정과 정합성

JSONL 입력이 `B`바이트일 때 문법 확인은 전후 `O(B)`다. 요청 본문에 대한 추가 제목 정규화와 플래그의 보관·전송을 생략했다. 실로그 집계 스레드 피크 힙은 20쌍 모두 줄어 중앙값이 52.27 → 50.60 MiB였다. 파일 준비 Worker 네 개 중 가장 높은 힙을 별도로 표본 조사한 결과는 63.35 → 64.51 MiB로, 6쌍 중 3쌍에서 줄었다. 이 진단은 20 ms 간격과 준비 1쌍을 사용했다. 합성 1만 건은 집계 직전 힙이 43.50 → 36.74 MiB, 직후가 52.62 → 46.63 MiB로 줄었지만 저장까지 포함한 피크는 63.57 → 90.53 MiB로, RSS는 167.05 → 182.84 MiB로 늘었다. 완료 후 강제 GC 뒤의 중앙값은 두 구현 모두 7.92 MiB였다. 피크 증가의 GC 시점과 할당 원인은 별도로 분리하지 않았다. 실로그 전체 시간의 쌍별 차이 가운데 50%는 −30.36~+22.87 ms였다. 전체 메모리 개선 기준으로는 보류했다.

각 입력에서 준비 3회 뒤 A·B 순서를 교대해 20회씩 측정했다. 세 입력의 120쌍에서 대화 수·토큰·일별 행·이름·원본 상태 및 네 평균 조회가 일치했다. 당시 표적 테스트는 A와 B 모두 56건 중 48건을 통과했고 같은 8건이 실패했다.
