기존 quota 진단으로 합성 응답의 파싱·QuotaService 갱신·표시 계산을 실행했다. 총 시간에 진단의 마지막 GC와 종료 처리가 포함된다. RSS는 초기화·종료·GC 표본과 피크 heap 표본에서 관측한 최댓값이다. 총 시간과 메모리의 짝별 표본 중간 50%는 모두 0을 포함했다.

시간과 메모리 모두 짝별 차이의 중간 50%에 0을 포함해 보류했다. Windows x64, Node 24.14.1에서 준비 3회 후 20쌍을 순서를 바꿔 계측했다.
