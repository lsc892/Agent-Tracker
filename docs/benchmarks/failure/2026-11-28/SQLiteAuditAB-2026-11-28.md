## 정합성

- 본 측정 210쌍에서 차이가 0건이었다. 저장 상태와 파일 ID, 순서가 있는 선택창과 대시보드 응답, 제공자·모델 비용과 일·월·세션·프로젝트 평균, SQLite 무결성과 외래 키를 대조했다. 도구 탭 응답은 화면이 소비하는 필드를 비교했다.
- 합성 입력은 생성 산식과 일치했다. 세 입력의 한 건 추가는 독립 원본 검산의 **1대화·입력 123·출력 7토큰**과 일치했다. 실로그 전체 합계의 독립 대화 단위 검산 범위는 추가분이다.
- 이동·마지막 참조 삭제·다른 제공자의 참조·소실 보존·롤백, 이름의 NULL·빈 문자열·동점·빈 페이지, 진단의 외부 커밋·롤백과 갱신 실패·취소를 별도 확인했다. 저장 후보는 v11·v25·v31 이관과 모델명의 NULL·빈 문자열·NUL도 확인했다.
