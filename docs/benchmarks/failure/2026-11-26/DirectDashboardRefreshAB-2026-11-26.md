# 임시 DB 없이 최근 30일 통계 열기 A/B

메모리 미리보기를 생략하면 복사·집계·조회와 첫 렌더링이 한 번 줄어 기존 DB에서 최종 표가 빨리 열릴 수 있다. 빈 DB에서는 전체 로그 처리가 첫 화면보다 앞서므로 첫 표가 늦어질 수 있다.

A는 현재의 메모리 미리보기 경로다. B는 같은 빌드의 갱신 요청에서 `recentUsage`를 생략한다. 파일 파싱과 Map 집계, 디스크 SQLite 쓰기와 COMMIT을 마친 뒤 기존 조회 API로 최근 30일을 읽어 첫 표를 그린다. 전체 갱신의 파일 선택·집계·트랜잭션 묶음은 두 경로에서 같다.

## 열기와 최종 표

## 실로그 처리 구간

각 구간 소요의 중앙값이며 단위는 ms다. 열기부터의 누적 시점은 마지막 다섯 행에 있다. Map에는 파일을 파싱하는 중에도 데이터가 들어간다. Map 최종 집계 행은 파싱이 끝난 뒤 저장할 요약을 만드는 구간이다. SQLite 쓰기에는 SQL과 묶음 사이의 대기 시간이 포함되고, COMMIT 행은 그 안에서 SQLite COMMIT 호출에 걸린 시간을 합친 값이다.

## 메모리와 DB 크기

힙은 통계 Worker의 V8 `heapUsed`다. 5ms 간격과 구간 경계에서 관측한 값으로 파일 파싱 Worker의 별도 V8 힙과 SQLite 네이티브 할당은 포함하지 않는다. RSS는 통계 Worker와 파일 Worker가 속한 확장 호스트 프로세스 전체다. 임시 DB 크기는 조회 시 SQLite 페이지 수와 페이지 크기의 곱이다.

## 요청 추가와 평균 조회

요청 추가는 위 표의 기존 DB 조건과 같다. 아래 평균 조회는 갱신 시간과 별도로, 갱신된 DB를 다시 열고 동일한 30일 필터로 페이지 전체를 반환할 때까지 측정했다. 평균 토큰은 제품의 완료 표본 수를 분모로 사용했다. 단위는 ms다.

| 평균 조회 | 실로그 A → B | 합성 10,000건 A → B | 합성 100건 A → B |
| --- | ---: | ---: | ---: |
| 일별 | 1.164 → 1.038 | 0.781 → 0.844 | 0.653 → 0.698 |
| 월별 | 0.873 → 0.832 | 0.692 → 0.666 | 0.607 → 0.643 |
| 세션별 | 1.963 → 1.932 | 0.791 → 0.748 | 0.669 → 0.645 |
| 프로젝트별 | 0.840 → 0.774 | 0.656 → 0.647 | 0.591 → 0.538 |

180쌍에서 A/B의 최종 30일 결과, 스레드 수, 토큰 합계, 네 집계의 그룹 수와 평균이 일치했다. A의 미리보기와 최종 표도 이번 사본에서 일치했다. 합성 입력은 생성기의 기대 토큰과 스레드 수를 대조했다. 실로그 조회와 평균은 같은 DB의 저장 일별 집계를 별도로 합산해 검산했다. 측정 후 원본 로그 사본 해시가 달라져 동일 실로그에 대한 원본 파서 독립 대조는 미측정이다.

## 측정 조건

2026-10-28~2026-11-26 Asia/Seoul 범위를 사용했다. Windows x64, AMD Ryzen 5 7500F, VS Code 1.147.0의 격리 복사본, 확장 호스트 Node 24.22.1과 파일 준비 Worker 최대 4개에서 측정했다. VS Code 업데이트가 진행 중이어서 설치 폴더를 복사한 뒤 그 복사본에서만 업데이트를 껐다. 각 조건은 준비 3쌍 뒤 A→B 10쌍과 B→A 10쌍을 교대했다. Worker와 DB 스키마 초기화, 원본 사본 준비, DB 복원, 검산은 열기 타이머 밖이다. OS 파일 캐시는 유지했으며 설치·마이그레이션과 파일 Worker별 힙은 미측정이다.

실로그는 Claude 12개·Codex 719개·추가 검증용 Claude 1개로 구성했다. 실로그 본문은 465,102,283바이트이며 압축 로그는 668개다. 기본 집계에는 전체 713스레드와 최근 30일 277스레드가 있었고, 최근 30일 토큰은 2,030,307,312개였다. 합성 10,000건은 500개 Claude 스레드에 요청을 20개씩, 합성 100건은 10개에 10개씩 넣었다. 최근 기간에는 각각 10개와 1개 스레드가 포함된다. 요청 추가는 세 입력 모두 기존 최근 Claude 스레드에 110토큰 응답 한 건을 추가했다. 실제로 큰 Codex 로그에 요청을 추가한 경우의 지연은 이번 실험에서 측정하지 않았다.

B는 기존 DB에서 최종 표를 빨리 열었고 빈 DB에서는 첫 표를 늦췄다. 이후 사용자 요청에 따라 B를 제품에 적용했다. [기능 결정 일지](../../../AgentTracker-일지.md) · [원시 표본과 빌드 식별자](DirectDashboardRefreshAB-2026-11-26.json)

`--direct`는 미리보기 코드가 있는 기준 커밋 `7b02b2c`를 사용한다. `VSCODE_EXECUTABLE`에 격리된 VS Code 실행 파일을 지정한 뒤 실행한다.

```powershell
node --no-warnings tests/benchmarks/dashboard-first-page-ab.cjs --direct --pairs=20 --warmups=3 --output=tests/results/benchmarks/DirectDashboardRefreshAB-rerun.json
```
