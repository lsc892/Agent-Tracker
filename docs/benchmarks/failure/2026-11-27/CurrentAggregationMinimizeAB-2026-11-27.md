# 대화·Skill 집계 최소화 A/B

응답 후보 정렬을 `Map` 비교로 바꾸고 도구 호출의 위치 배열과 저장 입력 복사를 줄이면 갱신 시간과 메모리 사용량이 감소할 것으로 가정했다. A는 현재 대화·Skill 기능에서 이번 최소화만 되돌린 사본이다. B는 응답 비교, 도구 호출 위치 보관, 저장 입력 구성의 최소화가 적용된 작업 트리다. 두 소스 사본의 차이는 `memoryAggregate.ts`, `sourceWinners.ts`, `memoryStore/index.ts`, `rollups.ts` 네 파일에 한정된다.

후속 계측 뒤 사용자 요청에 따라 네 파일을 A의 구현으로 복원했다.

## 판정

- 실로그 최초 수집이 중앙값 21.07ms 빨라졌고 B가 20쌍 중 14쌍에서 빨랐다. 쌍별 시간 차이 `B − A`의 가운데 50%가 −93.63~+35.43ms였고, 1건 추가 전체는 중앙값이 0.62ms 늘었다. 전체 갱신이 일관되게 빨라졌다는 근거는 얻지 못했다. 실로그 최초 수집 시간 중 변경 원본 준비가 약 91%를 차지했다.
- 실로그 최초 수집의 저장 배치는 중앙값 6.18ms 줄었고 16쌍에서 빨랐다. 메모리 집계는 중앙값 4.03ms 늘었고 15쌍에서 느렸다. 코드에서 후보 전체 정렬을 제거했으며, 개별 변경의 실행·할당 비용을 분리하는 계측은 수행하지 않았다.
- 실로그 최초 수집에서는 응답 비교 직전 힙이 20쌍 모두 감소했고 중앙값은 1.41MiB 감소했다. 이후 피크 힙은 20쌍 모두 증가했고 중앙값은 3.44MiB 늘었다. 합성 10,000대화에서도 피크 힙이 20쌍 중 19쌍에서 증가했다. 실로그 전체 프로세스 RSS는 10쌍씩 방향이 갈렸다.

## 응답 병합만 바꾼 후속 계측

같은 실로그의 파싱 결과를 메모리에 한 번 준비했다. B의 집계에서 응답 병합 메서드만 정렬 방식으로 바꾼 대조군과 `Map` 방식을 비교했다. 스킬 위치 보관과 입력 구성은 양쪽 모두 B와 같다. 시간은 준비 4쌍을 제외하고 20쌍을 교대 측정했다. 시작 전에 GC를 실행한 뒤 `finish()`의 경과 시간과 반환 직후 힙을 읽었다. 별도의 6쌍은 V8의 4KiB 간격 샘플링으로 병합 호출 아래의 누적 할당을 추정했다.

| 측정 항목 | 정렬 → `Map` |
| --- | ---: |
| `finish()` 시간 | 45.26 → 50.41 ms |
| `finish()` 직전 힙 | 42.29 → 42.31 MiB |
| `finish()` 직후 힙 | 78.00 → 82.43 MiB |
| 병합 호출 하위의 누적 할당 추정 | 30.59 → 35.01 MiB |

세션 425개의 병합 후보 29,123개는 세션 안에서 모두 고유했다. 세션당 후보 수 중앙값은 30개였다. 정렬 방식은 키 비교를 총 73,462회 했고 `Map` 방식은 29,123개 전부에 키 조회와 삽입을 했다. 이 입력에서는 중복을 줄여 얻는 이득이 0건이었고, `Map`의 키 처리와 항목 관리가 추가됐다. 정렬 방식을 바꾼 구간만 분리해도 `Map` 방식의 반환 직후 힙은 20쌍 모두 증가했고 시간은 14쌍에서 늘었다. 20개 시간 표본 쌍과 6개 프로파일 쌍의 집계 결과 해시는 일치했다. ## 측정 조건과 검산

2026-11-27 17:21~17:26, Asia/Seoul. Windows x64, Ryzen 5 7500F, Node 24.14.1, SQLite 3.51.2, 파일 Worker 최대 4개로 실행했다. 실로그 사본은 751파일, 506,096,130바이트이며 Claude·Codex와 Zstd 원본을 포함한다. 합성 입력은 고정 산식으로 두 제공자에 요청을 반씩 나누고 세션당 50개·5개 요청을 넣었다. 평균은 1건 추가를 커밋한 뒤 완료 대화를 분모로 전체 기간의 모든 페이지를 조회했다.

입력 및 시나리오마다 준비 3쌍 뒤 AB 10쌍과 BA 10쌍을 교대했다. 최초 수집은 매번 빈 DB, 1건 추가는 같은 기준 DB 사본에서 시작했다. 측정 시간에는 `refreshSummary`의 COMMIT과 파일 Worker 종료가 포함된다. DB 사본 준비, 조회 검산, 파일 해시 확인은 갱신 타이머 밖에서 처리했다. OS 파일 캐시는 유지했다.
