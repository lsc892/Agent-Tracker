## quota·설정 정리

- Claude는 처음 요청한 응답이 401일 때만 응답 본문을 정리하고 인증을 다시 읽어 한 번 요청한다. 두 번째 응답을 반드시 처리하는 경로가 있어, 반복문이 끝난 뒤 실행될 수 없던 인증 오류와 여섯 언어의 해당 문구를 삭제했다. [Claude 조회](../../../src/quota/claude.ts#L41)
- Codex는 계정 응답의 진단 알림과 계정 유형 검증을 한 메소드에서 순서대로 수행한다. quota 타이머는 확장 호스트의 Node 타이머에서 제공하는 `unref()`를 바로 호출한다. [Codex 계정 응답](../../../src/quota/codex.ts#L127) · [폴링 타이머](../../../src/quota/service.ts#L14)
- 홈 경로는 설정값을 해석할 때 한 번 읽고, 지역 코드가 있는 locale의 언어 부분도 전체 코드 조회가 실패한 뒤 한 번 구한다. 앱 초기화와 설정 갱신에는 준비·서비스 구성·화면 적용 단계에 한 줄 주석을 달았다. [경로 설정](../../../src/configuration.ts#L13) · [언어 선택](../../../src/localization/index.ts#L20) · [앱 초기화](../../../src/app.ts#L55) · [설정 갱신](../../../src/app.ts#L161)

## 검증

타입 검사, 린트, Webview 스크립트 문법 검사와 diff 검사를 통과했다. 벤치마크 원시 자료 164개의 Git blob을 이동 전후로 대조했다. 자동 테스트, 실제 계정 조회와 벤치마크 재측정은 수행하지 않았다.
