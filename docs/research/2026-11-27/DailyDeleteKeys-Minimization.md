# 일별 삭제 대조 SQL 구성 간소화

## 검토

[일별 입력 변환](../../../src/summary/db/dailyFacts.ts#L18)에서 만든 현지 날짜와 일별 키는 [저장 경로](../../../src/summary/db/rollups.ts#L71)에서 UPSERT와 삭제 대조에 쓰인다. 삭제 쿼리의 표·키·조건 조합은 집계 기준과 소실 원본 보존 여부로 정해지므로 모듈을 불러올 때 만들 수 있다.

## 적용

제공자·모델별 UPSERT와 두 가지 삭제 SQL을 모듈에서 한 번 구성하고 각각의 계측 단계를 함께 둔다. 일별 키 열 목록을 JSON 추출과 최종 비교식에 재사용한다. 저장 묶음에서는 소실 원본의 유무로 삭제 문을 고르고 기존 페이로드를 바인딩한다. [저장 SQL 구성](../../../src/summary/db/rollups.ts#L20) · [일별 키 조회](../../../src/summary/db/queries/rollup/source.ts#L67)

## 검증

소실 원본 보존 조건, 바인딩 순서, 제공자·모델 저장과 Skill 처리 순서를 diff로 대조했다. 모델의 NULL과 빈 문자열 구분, 빈 일별 키 목록과 기존 이관의 날짜 계산은 같은 경로를 사용한다. 타입 검사·변경 파일 린트·diff 검사를 통과했다. 자동 테스트와 성능 재측정은 미실행이다.
