# 일별 SQLite 입력의 임시 토큰 배열 제거

[저장 트랜잭션](../../../src/summary/db/memoryStore/index.ts#L41)은 각 스레드의 합계와 모델별 사용량을 [일별 집계](../../../src/summary/db/rollups.ts#L57)에 전달한다. [SQL 입력 변환](../../../src/summary/db/dailyFacts.ts#L15)은 검증한 값을 제공자용·모델용 JSON 배열로 만들고, SQLite에서 이를 읽어 일별 행을 교체한다.

스레드별로 만들던 임시 토큰 배열의 값 다섯 개는 제공자 행과 모델 내역이 없는 경우의 대체 모델 행에만 쓰였다. 값을 지역 변수에 두고 두 최종 행을 직접 구성하도록 반영했다. 모델 값 검증 순서, 캐시 값의 `undefined`·`null` 처리, JSON의 열 순서와 SQLite 트랜잭션 범위를 보존한다.

두 행의 필드 순서와 기본값을 기존 구현 및 SQL 열 정의와 대조했다. 실제 할당과 갱신 시간은 미측정이다.
