# 턴 누계 검사 갱신과 보정 정리

[수집 진입점](../../../src/summary/scanner/refresh/aggregation.ts#L8)은 원본별 누계 검사를 등록한 뒤 확정 응답을 반영한다. 기존에는 같은 키의 최신 검사로 교체할 때도 항목 객체를 새로 만들었다.

## 적용

같은 키의 최신 검사는 기존 항목의 원본·귀속·검사·순번을 갱신한다. 기존 항목의 누적값과 맵 등록 순서를 그대로 사용한다. 검사가 하나도 없을 때 키 생성을 건너뛰고, 일치하는 검사에만 합계를 누적한다. 보정할 수 없으면 진단을 남기고 다음 검사를 처리한다. [검사 갱신](../../../src/summary/aggregation/memoryAggregate.ts#L198) · [보정](../../../src/summary/aggregation/memoryAggregate.ts#L251) · [응답 누적](../../../src/summary/aggregation/memoryAggregate.ts#L284)

## 검증

변경 내역을 대조해 동점일 때 먼저 등록한 검사, 0토큰 응답과 응답 부재의 구분, 콜백·누계·누락 요청 진단 순서를 확인했다. 타입 검사, 변경 파일 린트와 diff 검사를 통과했다. 자동 테스트와 성능 재측정은 미실행이다.
