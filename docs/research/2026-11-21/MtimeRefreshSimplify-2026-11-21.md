# 수정 시각 갱신 경로 단순화

기준은 파일별 체크포인트를 제거한 작업 트리다. 수정 시각으로 고른 원본을 처음부터 재파싱하고, 필요한 관련 세션·부모 로그를 묶어 정합성을 보존한다. 이번 작업에는 사용자가 요청한 갱신 경로의 레거시 제거와 책임별 메소드 정리를 적용한다.

| ID | 상태 | 대상 | 변경과 보존 조건 |
| --- | --- | --- | --- |
| REFRESH-01 | 적용 완료 | [갱신 진입점](../../../src/summary/scanner/refresh/index.ts) | 잠금·종료·실패 처리와 스캔 단계 실행을 나눴다. 기준 시각·진행 이벤트·바이트 합산을 각각 한곳에서 처리한다. |
| REFRESH-02 | 적용 완료 | [탐색과 집계](MtimeRefreshSimplify-selection.md) | 경로별 파일 상태 하나를 만들고 필요한 스캔에서 관계 색인을 채운다. 집계가 Worker의 winner DTO를 직접 읽는다. |
| REFRESH-03 | 적용 완료 | [파일 읽기](MtimeRefreshSimplify-reader.md) | Worker 입력에 읽기에 필요한 필드만 보내고, 완료 바이트 위치와 중복 계측값을 결과에서 제거했다. |
| REFRESH-04 | 적용 완료 | [저장](MtimeRefreshSimplify-persistence.md) | 파일 관측 쓰기, 스캔 ID 전파, 이전 inode 조회·인덱스를 삭제했다. 연결 성분 저장과 전역 기준 시각 확정을 별도 함수에서 수행한다. |

## 적용한 흐름

`refreshSummary`가 잠금과 Worker 수명을 관리한다. 잠금 안에서는 기준 시각 읽기 → 수정·소실 탐색 → 후보 전체 파싱 → 관련 원본·부모 해소 → winner 병합 → 성분별 저장 → 전역 기준 확정 순서로 실행한다. 저장에는 파일별 방문 쓰기가 제거됐다. 이전 SQLite 파일의 `last_seen_scan_id` 열은 v21 호환용이다. 이미 저장된 출처와 내용 해시로 이동을 확인한다.

무변경 갱신에는 파일 수에 비례하는 수정 시각 조사와 메모리에서의 소실 확인이 필요하다. 스캔에서 이용하는 출처 열만 읽고 관계 색인은 채우지 않는다. 겹치는 루트를 지나 같은 경로를 다시 만나면 파일 ID를 재사용한다. 변경 파일과 필요한 관련 파일의 바이트 합을 B라 하면 본문 읽기와 파싱은 O(B)이며, 이번 단순화의 A/B에서 읽은 바이트가 일치했다.

## 검증

`npm run check`의 타입 검사·린트·Node 테스트 436개가 통과했다. 무변경 원본 행에 UPDATE가 발생하면 실패하는 회귀 테스트와, 겹치는 로그 루트에서 최초 등록·파싱이 한 번만 발생하는 회귀 테스트를 포함한다. 재시작·저장 실패 후 재시도, 기존 SQLite 인덱스 정리, 세션 재귀속·소실 보존도 확인했다.

이전 [수정 시각 A/B](../../benchmarks/2026-11-21/MtimeRefreshAB-2026-11-21.md)의 B 소스·빌드를 이번 A로 고정했다. 같은 JSONL 사본에서 두 시나리오를 준비 3쌍과 순서 교대 10쌍으로 실행했다. 각 행은 중앙값이며 단위는 ms다.

| 입력 | 무변경 A → B | 1건 추가 A → B |
| --- | ---: | ---: |
| 실제 855요청 | 118.89 → 108.83 | 469.63 → 446.12 |
| 합성 10,000요청 | 26.65 → 24.17 | 38.84 → 37.37 |
| 합성 100요청 | 6.94 → 6.20 | 11.41 → 11.02 |

78쌍 모두 요청·모델·도구·비용 데이터와 네 그룹 집계가 일치했다. 시간 표본의 범위는 겹쳤다. 파일 행의 관측 UPDATE가 제거된 점과 무변경 본문 읽기가 0바이트인 점은 각각 회귀 테스트와 실제 측정으로 확인했다. 원시 표본은 로컬의 `tests/results/benchmarks/MtimeRefreshSimplify-2026-11-21.json`에 보관했다. 실행기는 [mtime-refresh-ab.cjs](../../../tests/benchmarks/mtime-refresh-ab.cjs)다.
