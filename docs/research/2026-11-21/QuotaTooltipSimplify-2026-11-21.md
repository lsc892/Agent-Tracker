# 상태 표시줄 사용량 카드 렌더링 단순화

2026-11-21 작업 트리의 카드 생성 흐름을 검토했다. 상태 표시줄은 현재 quota와 설정을 전달하고 `createQuotaTooltip`이 Markdown 카드와 허용 명령을 구성한다. 검토 범위에는 상태 표시줄 연결 코드, 카드 구분선 스타일, 기존 테스트를 포함했다. [카드 생성](../../../src/ui/quotaTooltip.ts) · [상태 표시줄](../../../src/ui/statusBar.ts) · [구분선 스타일](../../../tools/vscode/statusbar-toggle-view.cjs) · [확장 테스트](../../../tests/node/extension.test.ts)

| 후보 | 상태 | 변경과 근거 |
| --- | --- | --- |
| 카드-01 | 적용 완료 | 기간 표의 사용률 행을 제공자 영역에 직접 붙여 셀별 임시 `MarkdownString`과 중간 문자열 배열을 제거했다. 정렬 행은 같은 구분 문자를 반복해 구성한다. `appendText`의 외부 문구 이스케이프를 사용한다. |
| 카드-02 | 적용 완료 | 제공자 ID는 `state.provider`에서 읽고, 제공자와 하단 링크에 반복된 구분선 문법은 같은 문자열을 사용한다. |
| 카드-03 | 유지 | 외부 라벨과 오류에 적용하는 아이콘 이스케이프가 최상위 카드와 제공자 영역에서 다르므로 별도 제공자 `MarkdownString`을 유지한다. |
| 카드-04 | 적용 완료 | 기간별 초기화 문구를 한 번 만들고 막대 폭 계산과 표시에 재사용한다. |

## 검증

- VS Code 1.147.0의 `MarkdownString` 구현으로 6개 언어, 11개 quota 상태, 60개 설정 조합의 Markdown과 렌더링 옵션을 비교했다. 3,960건 모두 일치했다. 외부 라벨과 오류의 Markdown 기호·테마 아이콘, 누락·만료·미확인 초기화 시각, 사용률 범위를 포함한다.
- `npm run check`의 타입 검사·린트와 Node 테스트 438개가 통과했다.
- VS Code 1.147.0에서 합성 quota 설정이 준비된 뒤 카드의 밝은·어두운 테마, 막대·구분선·문구 배치, 호버·클릭 고정과 다시 클릭해 닫기를 확인했다. 합성 quota와 언어 전환을 함께 실행한 추가 검증은 일본어 호버 종료를 기다리다 타임아웃됐다. [화면 검증 스크립트](../../../tests/vscode/statusbar-toggle.cjs)
